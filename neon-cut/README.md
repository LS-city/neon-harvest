# NEON CUT

A browser video editor with film-style filters. Everything runs on your device, so no uploads are needed.

**Features**
- Load a video by dragging it in or clicking **＋ Load video**
- Trim the clip with the timeline handles, and set playback speed from 0.25× to 2×
- 10 styles, each with an intensity slider: Original, Cinematic, VHS, Gloomy, Noir, Vintage film, Neon, Dreamy, Super 8 and Glitch
- Adjustments: brightness, contrast, saturation, warmth, film grain, vignette and letterbox bars
- Captions in 4 fonts, plus an optional VHS camcorder stamp
- Export to MP4 or WEBM at 480p, 720p, 1080p or the original size, plus PNG frame grabs

**Shortcuts:** `Space` play/pause · `I` set start · `O` set end · `←` `→` skip 1s · `,` `.` step one frame

Export runs in real time, so keep the tab open. It works best in Chrome or Edge.
